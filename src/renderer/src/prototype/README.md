# 原型不是规格

这个目录里的东西**只给人看**，不是待实现的代码。

## 它是什么

- 一张能点的草图：布局、层级、文案、状态，用来回答「这一屏该长什么样」。
- 全部数据是假数据（`RECORDS`、`INVENTORY`、`machine` 这些常量），全部按钮只有一条假反应（点击后改本地 state）。
- 启动方式：`npm run panel:preview` 后开 `http://localhost:5199/src/prototype/preview.html`，`?screen=<id>` 直达一屏。
- 应用不 import 它，`out/` 里没有它，删掉不影响任何功能。

## 为什么不能照着做

照着抄会把三类东西一起抄进产品：

| 原型里的东西 | 为什么不能抄 |
| --- | --- |
| 假数据（`'他们开雾了，中路小心'`、`412 ms`、`PID 20184`） | 真实值来自探针、账本、日志；写死一个数字等于把「测不到」变成「永远正常」 |
| 假反应（点「下载」进度自然涨到 1、点「测试」随机成功） | 真实路径要处理失败、断点续传、镜像切换；随机成功是反模式 |
| 为了看得见而放大的东西（每行都写满一句话、六行体检全是绿的） | 真实面板上大多数时候是空、是灰、是「还没测」；把它做成永远有内容会骗人 |

界面意图（哪一行放在哪、告警长什么样、什么该进抽屉）才是要落地的东西。

## 落地怎么做

- 落地以**票面**为准，不以这个目录为准。票面必须写：现状位置（`文件:行`）、要动什么、验收三句。
- 票面若写「见原型 `?screen=xxx`」，必须同时列出该屏**真实数据来源**与**空态/失败态**，否则不许开工。
- 需要视觉细节（像素、颜色、字号）时看 `shell/tokens.ts` —— 那是唯一视觉来源，但仍以面板最终实现的自有 token 为准。
