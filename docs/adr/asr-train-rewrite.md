# ADR：识别训练重写——只训可微调引擎，页面由状态卡驱动

- 状态：已接受（2026-11-09）
- 部分取代：`docs/adr/asr-finetune-leg.md`（两条腿并列出现在产品与页面里的部分）、`docs/adr/train-run-model-and-panel-pages.md`（识别训练页固定三段的部分）

## 背景

识别训练 v3 把微调做成了面板里的一等功能，但它把「引擎」这个概念直接暴露到了页面上：两条腿、两套脚本、两套产物、两套估时，页面固定分「数据 → 运行 → 产物」三段，用户要自己判断走到哪一步。真实使用里只有一条腿在工作，而页面的形状却由引擎数量决定。

这次不是修缺陷，是把功能重新定义一遍：旧实现只作参考，不作基础。

## 决定

- **只训可微调引擎，目标显式选**：训练目标由 `asrTrainEngine` 决定（引擎表里 `finetune` 非 null 的那几个）；空值时跟随 `asrActiveModel` 所属引擎。训练目标、数据集格式、导出方式、产物槽位全部由引擎表 `finetune` 栏决定。页面上不再出现「两条腿」的概念；「腿」退回成引擎的内部实现。
  - 为什么不再绑死现役：运行时模型和训练能力是两件事。删掉旧权重（只留底模）也要能训；「识别用 A、训练 B」也是真实需求。
  - 早先「跟着现役走」的写法在权重缺失时会静默回落到别的引擎，导致删掉 qwen3 之后再也选不回它——这是 2026-11-09 实测踩到的洞。
- **有微调能力是选引擎的前置条件**：不支持微调的引擎不进可选列表。这不是页面要处理的分支，而是一条不变量——引擎表里 `finetune: null` 的条目不得出现在训练目标列表里。
- **训练数据三源并列，一次全吃**：读稿录音（`## Gxx` 逐句组与自由说组）、自定义录音、纠错样本。不提供按来源或按组筛选的入口。
  - 自定义录音 = 页内自由录一段话，文本由人自己填，或先让识别模型转写再改，落定即成为样本。
- **两种训练形态，由数据与现状决定**：
  - **全量**：从底模重训，吃全部数据，产物覆盖上一份微调模型。
  - **增量**：从已微调的模型继续训，只吃还没被任何一轮训练用过的数据（录音、自定义录音、纠错样本都算）；没有已微调模型或没有新数据时不可用。
  - 磁盘上最多只有一份微调模型，两种形态写同一份产出，不并行存在。
- **训练完直接转正**：没有「待应用」状态，也不设回滚槽；导出成功即替换训练目标引擎的现役目录，并把 `asrActiveModel` 切到它（否则会出现「提示已换上新模型，说话还在用旧引擎」）。替换失败时保留旧模型并落到「上次失败」。需要版本控制时另做。
- **页面骨架改成状态机**：一张状态卡发起全部动作，数据与历史降级为卡下面的详情。
  - 状态：缺环境 / 数据不足 / 可开训 / 训练中 / 现役 / 上次失败。
  - 每个状态只有一个主动作；「全量 / 增量」是「可开训」状态里的第二个选择，不是两个状态。
- **迁移只留数据与底模**：保留全部录音、自定义录音、纠错样本，以及未微调的底模；删除旧微调产物与回滚槽；训练记录（`runs.db`）清空重来。旧 run 记录只有旧代码能正确解释，带进新模型是负担。

## 后果

- 页面文案与数据模型里不再有 `qwen3-sft` / `funasr-paraformer` 这类词；它们只活在引擎表与训练执行层。
- 删掉按腿分支的估时、目标步数、学习率默认值，改为按引擎查表；新增引擎只改表，不改页面。
- 没有回滚：一轮训练如果导出成功但效果变差，唯一的退路是再做一轮全量。这是接受得了的代价，版本控制留到以后再加。
- 三种数据源必须在账本里可区分（来源、文本来源、是否人工改过），否则「数据够不够」和「训完有没有变好」都无从判断。

## 落地（与旧页面的差异）

- `applyAsrFtModel()` 由训练线程的终态路径调用（`src/main/services/train/manager.ts` 的 `finish()`），页面不再有「应用 / 回滚」两个按钮；导出并换模成功的 run 记 `applied`，只训练成功但换模失败记 `trained`。
- 自定义录音就是脚本组 `G99`（`CUSTOM_GROUP`）：先写一句文本（`appendScriptLine` 追加到该组末尾），再录制，落盘后写数据集账本。当前实现要求先有文本；「先让识别模型转写、再改」留作后续。
- 识别训练页从三段式改成「左侧四步 + 状态头」，音色训练页不动。

## 仍然不做（本轮边界）

- 不做数据筛选/排除录音组的能力。
- 不做外部 wav 导入（自定义录音必须在软件内录）。
- 不改音色训练页的三段结构。
