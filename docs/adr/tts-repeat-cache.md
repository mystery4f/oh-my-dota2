# ADR：sovits 重复句缓存

## 背景

Dota 聊天重复率高（「gg」「打得好」这类短语反复出现），每次都重烧一遍显卡。而同一段音频的合成结果是确定的，缓存可以直接回放。

## 决定（2026-10-31 烤问定稿）

- 粒度：**段粒度直 key**。缓存挂在 `synthesizeSovits` 上，key = 合成文本 + 语速 + 参考音频路径 + 转写文本。朗读文本带「某某说，」前缀，不同人念同一句整文不同不命中——接受的折中，换取实现最简单
- 容量：**内存 50 条**（上限约 20 MB），LRU 淘汰
- 生命期：应用重启清空；切音色 / 切权重（`applySovitsVoice`）立即清空，防止吃到旧音色的音频
- 命中时日志 `TTS_CACHE_HIT`，未命中照常合成后入缓存

## 否决的备选

- 剥前缀后再 key：命中率高，但「某某说」前缀没法和缓存音频拼回，放弃
- 落盘持久化：重启也命中，但切音色后的失效清理复杂度上一个台阶，不值

## 后果

- 命中的句子 0 毫秒 0 显卡
- 命中率取决于前缀设置与聊天内容，无强保证
- 用户手工绕过应用直调 api_v2 切权重时缓存不感知（应用内切换才有清空钩子），重启兜底
