# 驾驶室验收表（面板 → 驾驶室，`?s=helm`）

这张表只收**只能靠眼睛/耳朵判**的部分（`#167` 频道单独静音与一句话链、`#165` 三动作与监听行、`#170` 最近几条）。规矩与耳验单同源：开关只在面板点，**不许手改 `settings.json`**，不许调用真实模型，判据只认面板与 `<数据目录>/logs/`，控制台不算证据。

谁关票：人眼/人耳类只有测试能关，实现者不得自己关。回报格式见文末。

## 前提

- 真局在进行（GSI 连通，面板「总览」能看到局号与比赛时间），队里有人说过话。
- 合成引擎是「联网 · 神经语音」或「本地 · 离线模型」（`ttsEngine` 停在 GPT-SoVITS 且 `127.0.0.1:9880` 没起时，一个字都不出声，会把下面每一条都读成失败）。
- 已打开 `<数据目录>/logs/voice-chain.jsonl`，会用 `kind` 搜（`speak-skip` / `half-duplex-drop` / `half-duplex-skip`）。

## 已由探针证明的部分（别重复验，也别当成没验）

在 `31c51b2` 上实跑，五条全绿：`--helm-empty-probe` 69/69、`--speaker-channel-probe` 28/28、`--voice-chain-probe` 24/24、`--half-duplex-probe` 36/36、`--speak-skip-probe` 19/19、`--speak-mute-probe` 18/18。

它们钉住的是**规则**，不是画面：抬头六格缺块一律写 `—` 且顺序固定；没快照时文案逐字是「先把 GSI 那条连通」；没频道时页尾仍解释为什么没有静音开关；`hero` 为空的行 `muteable=false`（哪怕静音名单里恰好有同名也不算）；有英雄名才可静音、且大小写不敏感；最近几条最多 5 行、按时间倒序、单行截断、空白句子不占位；驾驶室勾出来的名单走 `reason:"muted-player"`（不是 `mute`）。

## 步骤 · 抬头（三种状态，谁都不许冒充谁）

- 看：面板 → 驾驶室 →「这一局」组。
- **第一种：还没收到过快照** —— 整组只有一行「先把 GSI 那条连通」，不许出现六个 `—` 的空壳。
- **第二种：在局里但字段缺** —— 六个格子（局号 / 比赛时间 / 英雄 / 等级 / 状态 / 最后一帧）都在，缺的那个写 `—`，尤其**等级不许猜成 `Lv1`**。
- **第三种：满状态** —— 局号是这一局的、比赛时间在走、等级是 `Lv7` 这种带前缀写法、状态在「活着 / 复活 0:24 / 阵亡」三者之一、最后一帧是「4 秒前」这种相对时间。
- 判不过：抬头出现玩家名字、出现 `Lv1` 而英雄确实有等级、或者没快照却摆出空表格。

## 步骤 · 频道列表只许座位写法

- 看：「谁在说话」组。
- 算过：每行标签是 `我` / `队友 2` / `对手 3` 这种**座位**写法；认不出座位时写 `—` 或整页说「认不出谁是谁」，绝不用英雄名或玩家名顶上。
- 为什么必然如此：真局**永远不推 `allplayers`**（实测 3499 帧一局零次），所以标签只能从座位推。看见「某个玩家 ID」出现，要么是假数据，要么是实现从别处猜了名字——两种都要记下原文。
- 算不过：出现任何形如昵称的字符串；或者五个频道里有一个写了英雄名。

## 步骤 · 频道单独静音（只有拿到英雄名才有开关）

- 看：「谁在说话」组每一行的右槽。
- **有 `hero` 的行**：出现勾选框 + 「在读 / 已静音」；勾上后**只有这个人**不再被念，同队其他人照常；取消勾选立刻恢复（不用重启）。
- **没有 `hero` 的行**：**不许出现任何控件**（连灰掉的勾选框也不行），整页底部那句解释在：「GSI 不给别人的名字，按人静音要等拿到英雄名；现在只能在「不念谁」里按名字写」。
- 与「不念谁」是同一份名单（`settings.ttsMuteHeroes`）：在驾驶室勾了某人，去对讲页「不念谁」应该能看到同一个名字；反过来也一样。
- 日志判据：勾上后那个人被跳过时，`logs/voice-chain.jsonl` 里那一行是 `"kind":"speak-skip","reason":"muted-player"`。写 `"mute"` 说明被当成了总开关静音，判不过。
- 判不过：没有英雄名的行也有开关；勾了以后**全体**不念（像把总开关关了）；取消后要等重启才恢复。

## 步骤 · 一句话链

- 看：「一句话链」组。
- 正常态：左「听到」是识别原文（没听清时给「没听清」+ 黄色标记），右「说了」是译文，灌进设备时后接 `· 灌入「CABLE Input…」`。
- 失败态：多一行「卡在 `<阶段>`：`<一句原因>`」——原因是**第一句**、被截断过，不是整段栈。
- 四种空态必须四句话：`这局还没对讲过` / `不在对局里` / `上一句在别的局，这里不显示` / `这句话读不到`。任意两句写得一样，就是判据退化。
- 跨局：上一局的最后一句**不许**贴到这一局；换局后应立刻变成「这局还没对讲过」。
- 判不过：把上一局的话当这一局显示（这是本票最贵的错误）；把阶段名直接拼给人读（应是人话）。

## 步骤 · 监听行与三个动作（`#165`）

- 「它在听什么 / 刚说了什么」：左半是帧龄三档，三种「没东西」三句话（`还没收到过一帧` / `这一局还没发生可播报的事` / `状态读不到：<第一句>`）；右半是时间线最新一条，属上一局时**不显示**。
- 三个动作按钮：说话 / 看一眼 / 呼出，键名一律来自活表（改键后跟着变）；没绑键时按钮禁用并说「这个动作还没绑键」；浮层关着时「呼出」禁用并说「浮层现在是关的」；看一眼在跑时说「正在看…」并禁用。
- 连点去抖：说话按钮半秒内连点第二次被挡回时说「刚触发过，稍等半秒」，**不静默、也不起两次录音**。
- 判不过：两个原因叠着写在一行；或者禁用但不给理由。

## 步骤 · 最近几条

- 看：页面最底部「最近几条」。
- 算过：最多 5 行，最新在最上面；没说过话的席位**不占位**（一局开头不该是五行空气）；每行是「座位标签 + 一句话」，超长截断成一行、不换行；空态是「这一局还没人说话」。
- 对讲那句**不上墙**（同一句话出现在两处，用户会以为是两件事）。
- 判不过：出现玩家名；把对讲内容也列进来；或满屏换行把行高撑开。

## 两段旧判据不放松（`#93` 与 `#129`）

这两段仍以 `logs/voice-chain.jsonl` 的 `kind` 行为准，改动驾驶室期间不许回退：

- 朗读跳过：`"kind":"speak-skip"` 的 `reason` 必须能分开三种——总开关 `mute`、按人 `muted-player`、自己的话 `own`。
- 半双工：`"kind":"half-duplex-drop"`（带 `stage` = `announce` / `echo` / `test` / `reply` / `interpret`）与 `"kind":"half-duplex-skip"`（`durationMs:null`，**不计入** `total`/`dropped`）。时长没量到时写「未记账，不是没丢」。
