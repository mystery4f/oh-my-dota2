# 一局内可做完的耳验单（给老板照着按，约 40 分钟）

依据 `docs/agents/ear-acceptance.md`（`73d7189`）。规矩：所有开关只在面板点，**不许手改 `settings.json`**；**不许调用真实模型**；判据只认 `<数据目录>/logs/` 里的日志，控制台不算证据。

## 开局前 3 分钟

- 面板 → `关于 → 诊断`：记下数据目录路径；确认能看到「自己说话时的回声」这一行。
- 用文本编辑器打开 `<数据目录>/logs/voice-chain.jsonl`，学会按 `half-duplex-drop` 搜（这个文件一直在追加，别关它）。
- 面板 → `浮层与对局`：记下「对讲/同传」热键（默认 `Alt+Shift+V`）。

## 现场三个盲区（遇到就如实记，不许算通过）

- **`durationMs` 为 null**：窗口不开，链记录里 `durationMs` 是 null 时写「**没在守，不是没丢**」；同时 `logs/voice-chain.jsonl` 会有一行 `"kind":"half-duplex-skip"`（带 `stage` 与 `durationMs:null`），它只是痕迹，**不算**进 `total`/`dropped`。
- **腿名一直是 `unknown`**：说明渲染层 → 主进程那一跳断了（`voice.api.voicePlayback(ms, leg)` 没到）；**腿名一直停在 announce/echo 不清**：说明「播完关窗」没接上。这两种都是现场能看见的独立故障，不算「没生效」。
- 腿三若本局没生成回放条目：写「**未测到，原因：本局没有生成回放条目**」，不算做过。
