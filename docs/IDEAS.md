# oh-my-dota2 · 功能想法池

只收录未排期的想法。哪条立项了就搬进 `docs/PLAN.md`，从这份文件里删掉。想法不设门槛，但不写实现细节——实现是立项时的事。

## 情报类（让你多赢）

- **敌方情绪雷达**：auto-zh 本来就把敌方全频道的嘲讽都翻出来了，但和平常消息混在一起。加一层分类，给每条敌方消息打「骂队友 / 内讧 / 挑衅」标签，浮层直接显示「他们 3、5 号位吵起来了」。对面内讧就是优势窗口，这信息现在白白流走。实现便宜：翻译结果已经在账本里，加个关键词 + 小模型判定就够。
- **玩家档案（本地）**：GSI 名单给全了昵称 + 英雄，本地存一张「遇见过的人」表：这人上次是演员、那次是大腿，再遇到自动标徽章。零注入、纯本地，解决 CN 刀圈最真实的痛点。
- **战绩速查**：玩家档案的延伸。悬停名单某人，走 OpenDota 免费接口拉胜率、常用英雄、段位，浮层小卡片显示。要过代理、要缓存，和玩家档案是天配。

## 对讲链路（让你说话更顺）

- **流式对讲**：现在是「说完 → 等识别 → 等翻译 → 等合成」，一句话出去 2-3 秒。改成边说边识别、识别完一段就翻，延迟有望压到 1.5 秒内。工程量大，但对讲体验的天花板。
- **局势感知快捷语**：GSI 事件（肉山死、塔掉）一响，召唤面板自动浮出「nice rosh / wp」候选，点一下走声出，不用按热键说话。打架时省的两秒是真值钱。
- **自定义术语表**：面板里加几行「我的黑话 → 英文」，朋友昵称、战队梗，混进现有词表逻辑。小活，但每个人都不一样。

## 音色类（让声音更像你）

- **用自己的声音说英文**：asr-ft 的口音录音和 GV 微调录音本来就是同一个人录的，一套素材喂两边：微调出你自己的音色，跨语种说英文。队友听到的是「你」在讲英语。音色包管线全是现成的。

## 外部灵感

### Dota2-Post-Game-Analyzer（用户推荐，2026-11-07）

<https://github.com/Wentao-tao/Dota2-Post-Game-Analyzer>

iOS 应用（SwiftUI / MVVM），定位是「虚拟教练」而不是数据面板：局后调 OpenDota 免费接口（`/matches/{id}`、`/players/{id}`、`/heroes`）拉对局与玩家数据，再用 GPT-4o 生成个性化复盘建议，提示词按英雄和分段定制。

对我们的启发：

- GSI 本来就给 `matchid`，局后接 OpenDota 就是现成的「局后报告」路线——这正是想法池里一直缺的一块。
- 我们独有它没有的素材：整局的聊天翻译时间线、GSI 事件序列、朗读日志。「教练」不但能看数据，还能引用这局谁说过什么、什么时候吵起来的，复盘比纯数据教练有味道得多。
- 它的提示词分层思路（英雄特化 + 分段适配）可以直接抄：给低分段讲补刀，给高分段讲资源分配。


### dota2-translate-ptbr（用户推荐，2026-11-07）

<https://github.com/yuritsukahara/dota2-translate-ptbr>

巴西社区项目：把 Dota 2 英雄语音「翻译 + 配音」成巴西葡萄牙语。三条腿——社区真人配音包；游戏内字幕方案（反编译审计把全部 75,520 条英雄语音和变体逐条对齐到游戏事件与音频）；一个 .NET 8 安装器（自动扫所有 Steam 库定位 Dota，从 GitHub 下载带版本校验的整合包，可选「只装字幕」或「字幕 + Axe 示例配音包」）。

对我们的启发：

- 「英雄语音 ↔ 游戏事件」的整表映射是个现成路标：哪天做事件提醒的语音表现（肉山死、塔掉时念一句英雄原声），或者给 GSI 事件配台词，直接参考它的事件对齐方式。
- 安装器的「扫 Steam 库 + 版本校验包 + 可选组件」分发形态，和我们的音色包管线（voicepacks.json 清单 + 下载校验）同构，装机体验可以对照着补。
- 它验证了零注入边界内的社区语音包完全可行：资源包独立分发、不碰游戏进程，和我们「不注入」的红线一致。

### dota_diary_cli（用户推荐，2026-11-07）

<https://github.com/filipejunqueira/dota_diary_cli>

个人 Python CLI：把对局当日记记进本地 sqlite，常规解析之外还对比赛数据做 PCA 分析——找哪些维度和你赢球相关。

对我们的启发：

- 「日记」这个角度有意思：数据之外留一栏人写的注（今天手感、和谁双排、为什么送）。局后报告只有数据没有这几句注，复盘坚持不了几周。omd2 已有 matchid 和账本，加一张注记表就是「对局日记」。
- PCA 这类分析回答「我输的局都差在哪个维度」，比看 KDA 直观，思路可以借给局后报告。

### dota2-assistent / AegisForge（用户推荐，2026-11-07）

<https://github.com/xyoko/dota2-assistent>

网页版战术助手（React，Cloudflare Pages/Workers）：英雄克制推荐（按位置分路）、1v1 对线模拟器与强度曲线、英雄↔道具克制百科、出装沙盒、版本强度榜，重模块全部懒加载。

对我们的启发：

- 对局内我们已经有 GSI 名单：进对局拿敌方五个英雄，接一套克制数据，浮层就能给「这把难打的点 + 推荐道具」。把选人阶段的攻略工具搬进对局内，是这类网页工具没有的时机优势。
- 它按位置给推荐，提醒我们阵容情报不能只报「缺控制」，要落到具体位置。
- 数据新鲜度是这类工具的死穴，接 OpenDota 的思路和「战绩速查」想法是同一条线。
