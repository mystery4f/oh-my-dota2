## 一句话

把「十三页设置」换成「一屏驾驶室 + 三个热键」：产品的时间单位从**模块**换成**一局**。

## 现状解剖

| 症状 | 证据 | 后果 |
| --- | --- | --- |
| 页多、行多 | `src/renderer/src/panel/pages/` 共 4209 行、132 个 `Row`；`asr-train.tsx` 27 行、`talk.tsx` 21 行 | 想改一件事先要找到它在哪页 |

## 三个时间尺度

- **这一局**（默认落地）：`helm`。抬头一行事实（时间 / 比分 / 经济差 / 下一件事）、一条时间线（每条右边一个动作）、五个频道（点一下单独关掉某个人的朗读）、三个固定动作（说 / 看 / 呼出）、一行「它在听什么、刚说了什么」。
- **平时**：`talk`、`read`、`engine`、`voice`、`packs`、`asr`。开赛前调一次。对局中要改的高频项，收进驾驶室的「说与听」抽屉（6 项，含语音命令）。
- **一次**：`wire`、`overview`、`hotkeys`、`about`。装环境、体检、改键位、交日志。

导航只按这三层分组，不再按模块分组。原「对局」组里的五页设置全部降级：说话与听话进「平时」，总览降级成「体检」进系统组。

## 五条硬规则

- 默认没有主界面：`bare` 那一形态里桌面上只有一条 132×34 与三个热键；只有「装环境 / 训练 / 查日志」才开窗口。
- 对局中最多四个动作：说、看、呼出、关掉某个人。第五个动作出现就说明该收进抽屉。
- 一条告警一句话，并且带一个能按的按钮（例：虚拟声卡「驱动已装但端点还没出现」→ 重新检测）。
- 测不到就写「测不到 + 原因」，不许亮绿；认不出失败形状就保留原始日志尾巴，不许猜。
- 颜色不是唯一信息：状态一律「色块 + 符号」（✓ / ⚠ / ✕ / ●），灰度截图也要能分辨。

## 屏清单（16）

`helm` 这一局 · `bare` 无窗口形态 · `board` 副屏（第二块屏上 320 宽的一条，与浮层同一份快照） · `talk` 它怎么听·说 · `read` 它怎么念 · `overlay` 浮层 · `chatout` 直发 · `engine` 翻译引擎 · `voice` 音色训练 · `packs` 音色包 · `asr` 识别训练 · `overview` 体检 · `wire` 接线 · `hotkeys` 热键 · `about` 关于。

默认落地 `helm`；`?screen=` 可直达任意一屏，供评审时逐屏比对。

## 副屏的形状（124a）

不是第二个面板：320 宽一条，六项（局号 / 状态 / 比赛时间 / 我玩谁 / 存活或复活倒计时 / 最后一帧多久前），数据全部来自与浮层同一份 `window.api.matchSnapshot()`。缺块写 `—`，不许猜成 Lv1，也不许进断流告警 —— 「那一帧没这个块」和「cfg 没生效」是两件事。

## 与 v2 的差别

v2 的目标是「8 个一级分区 + 全局搜索」，本质还是把设置整理得更整齐。v3 不再整理设置，而是把设置移出对局：默认一屏里没有设置，只有动作与记录。

## 不做的事

- 不新增常驻窗口、不做托盘以外的第二个入口。
- 不在驾驶室里放引擎地址、密钥、模型路径这类只在装机时看一眼的东西。
- 不把面板做成「什么都能干」的工作台：能干的越多，对局中越找不到那三个动作。

## 落地顺序

- 先做 `helm`（含说与听抽屉、五个频道、语音命令），其余十二屏暂时保留旧页。
- 再把「平时」六页按新 token 与行结构重排，删掉与抽屉重复的行。
- 最后做 `bare`：把面板降级成只在三种情况下打开的窗口。

## 验收（人眼，不看探针）

- 灰度截图能分辨三种状态（待命 / 在听 / 在念）。
- 对局中从「想改语速」到改完，不超过两步，且不离开当前屏。
- 关掉一个人的朗读，其他人照常念；关掉之后重启仍然关着。
